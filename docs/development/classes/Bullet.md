# Bullet

## 역할과 접근 경로

실제로 발사된 탄환 한 발의 이동·피해·수명·관통을 보관하는 dataclass입니다. `game.combat.bullets`의 원소이며 [entities.py](../../../src/space_z/game/entities.py)에 정의되어 있습니다. 자체 이동 메서드는 없고 `Combat`이 상태를 변경합니다.

## 이동과 수명

| 속성 | 의미와 단위 | 초기값 또는 기준 | 변경 함수 |
|---|---|---|---|
| `x`, `y` | 탄체 중심의 월드 좌표, px | 포구·벽 검사 결과를 생성자에 전달 | `Combat._move_bullets()` |
| `vx`, `vy` | 가로·세로 속도, px/frame | 방향 × 실제 탄속 | 현재 탄환 이동에서 속도 자체는 유지 |
| `life` | 남은 수명, 게임 프레임 | 실제 무기 수명 × 개별 패턴 배율, 최소 1 | `_move_bullets()`가 매 프레임 감소 |
| `prev_x`, `prev_y` | 이번 이동 구간 시작 좌표 | 기본 `None`; 생성 직후 포구 구간 검사에 잠시 사용 | `_emit_shot()`, `_move_bullets()` |

수명 70프레임은 FPS가 60일 때 약 1.17초입니다. 메뉴에서는 게임 프레임이 멈춰 수명도 줄지 않습니다. 충돌이 없다면 기준 사거리는 탄속 × 수명이며 벽·대상 충돌로 더 일찍 소멸할 수 있습니다.

## 공격과 충돌

| 속성 | 의미 | 초기값 또는 기준 | 변경 함수 |
|---|---|---|---|
| `owner_id` | 발사한 선체의 고유 번호 | 생성자에 발사자 번호 전달 | 생성 시 지정 |
| `team` | 공격 진영 | 생성자에 발사자 진영 전달 | 생성 시 지정 |
| `damage` | 대상의 받는 피해 배율 적용 전 피해 | 무기·숙련·개별 패턴 계산값 | 생성 시 지정; 명중 함수는 조회 |
| `radius` | 실제 충돌 반지름, px | 선체 반지름 × 포신 `caliber` | 생성 시 지정 |
| `kind` | 표시 종류 | 기본 `plasma`; 저격 계열은 `shell` | `_emit_shot()`에서 지정 |
| `blast_radius` | 범위 피해 반지름, px | 기본 `0.0` | 생성 시 지정; 양수면 명중 시 폭발 처리 |
| `pierce` | 명중 뒤 탄환을 유지할 수 있는 남은 관통 횟수 | 기본 `0`; 저격 계열은 `1` | `_bullet_hit()`가 관통 때 감소 |
| `hit_ids` | 이미 맞힌 개체의 번호 집합 | 탄환마다 새 빈 집합 | `_bullet_hit()`가 관통 때 추가 |

`_bullet_hit()`는 이동 선분과 교차하는 대상 중 먼저 닿은 하나를 선택합니다. 관통이 남으면 수치를 줄이고 대상 번호를 기록한 뒤 탄환을 유지합니다. 다음 판정에서 같은 대상은 제외합니다.

실제 충돌 크기는 포신과 연결됩니다. `Renderer`는 작은 탄환이 안 보이지 않도록 표시 폭을 화면 기준 최소 4px로 보정하지만 `radius`를 바꾸지는 않습니다. 저격 계열은 포탄 그림과 발광을 사용합니다.

> [!note]- 이전 무기에서 남은 비활성 필드
> | 속성 | 의미 | 기본값 | 현재 처리 |
> |---|---|---|---|
> | `arming_frames` | 이전 지뢰의 무장 대기 | `0` | 현재 이동·발사에서 미사용 |
> | `homing` | 이전 유도탄의 추적 여부 | `False` | 현재 이동·발사에서 미사용 |

## 관련 함수

| 함수 | 읽는 상태·호출 조건 | 변경·요청 | 반환 |
|---|---|---|---|
| `Combat._emit_shot(...)` | 발사할 기체·패턴·무기 수치 | 탄환 생성, 생성 구간 명중 검사 후 목록 추가 | `None` |
| `Combat._move_bullets()` | 매 프레임, 현재 탄환·지형 | 좌표·이전 좌표·수명 변경, 벽·개체 피해 요청과 목록 정리 | `None` |
| `Combat._bullet_hit(b)` | 이동 구간·공격 진영·이미 맞힌 번호 | 대상 피해·관통·명중 집합 갱신 | 탄환을 소멸시킬지 `bool` |
| `Renderer._draw_bullet(b)` | 위치·속도 방향·진영·종류·반지름 | 화면 출력만 수행 | `None` |

학습 관찰 생성기는 가까운 적 탄환의 상태를 읽습니다. 탄환 상태를 보관하는 클래스와 실제 처리 함수가 분리되어 있다는 점은 [[development/classes/Combat|전투 문서]]에서 이어서 볼 수 있습니다.
