# 객체 간 동작 흐름

하나의 동작이 여러 객체의 상태를 어떻게 바꾸는지 설명합니다. 단계에서 클래스 문서의 관련 상태로 이동할 수 있습니다.

1. [탄환 발사](firing-projectiles.md): 클릭 → 발사 조건 → 점사 예약 → 탄약 소비 → 탄환 생성.
2. [피해와 적 처치](damage-and-kills.md): 명중 → 체력 → 사망 → 이벤트·점수·성장.
3. [강화와 진화](upgrades-and-evolution.md): 선택 → 플레이어 능력치 → 적 대응 갱신.

전체 프레임 순서는 [[development/classes/GameCore#한 프레임의 순서|GameCore.step]]에서 확인합니다.
