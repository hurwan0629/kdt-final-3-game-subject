# 탄환 발사

## 시작 조건과 참여 객체

플레이어의 클릭·버튼 유지 또는 적의 공격 판단이 발사의 시작점입니다. 입력 앱 → 코어 → 전투 → 기체·탄환 상태 순서로 연결됩니다. 일반 공격과 기존 예약 점사는 처리 조건이 다릅니다.

관련 상태: [[development/classes/GameApplication#시간과 발사 입력|입력·발사 차단]], [[development/classes/Tank#무장과 탄약|무장·예약 점사]], [[development/classes/Combat#발사 상태|전투의 발사 처리]], [[development/classes/Bullet|탄환 한 발]].

## 처리 순서

1. 앱이 클릭 요청·현재 버튼·메뉴에서 넘어온 발사 차단·강화 UI 영역을 확인합니다. 조준 마우스를 월드 좌표로 변환합니다.
2. `GameCore.step()`은 플레이어 이동·조준과 적별 AI·발사를 처리한 뒤 플레이어의 `Combat._fire()`를 호출합니다. 적은 AI에서 같은 발사 함수를 사용합니다.
3. `_fire()`는 먼저 사망·플레이어 재장전 여부를 봅니다. 막혀 있으면 예약을 비우고, 가능하면 현재 프레임에 도달한 예약부터 발사합니다.
4. 발사 대기가 남았다면 하나 줄이고 새 묶음을 시작하지 않습니다. 대기가 없고 새 발사를 원할 때 정의·개체 배율·숙련으로 무기 값을 계산합니다.
5. 지연 없는 패턴은 즉시 발사하고, 지연 있는 패턴은 `Tank.pending_shots`에 예약합니다. 탄약 제한이 켜진 플레이어는 실제 방출마다 잔탄을 하나 소비합니다.
6. `_emit_shot()`은 실제 기체 위치·방향·포신 정의로 포구를 계산하고 벽을 검사한 뒤 `Bullet`을 만듭니다. 생성 구간에서 바로 명중할 수도 있습니다.
7. 유지할 탄환을 `Combat.bullets`에 추가합니다. 코어의 뒤 단계에서 탄환 이동·수명·명중을 처리하고 렌더러가 결과를 그립니다.

## 바뀌는 상태

| 보관 객체 | 바뀌는 값 |
|---|---|
| `GameApplication` | 소비한 클릭 요청, 현재 행동 |
| 발사한 `Tank` | `ammo`, `cooldown`, `pending_shots` |
| `Combat` | `bullets`, 플레이어 묶음 시작 시 `player_shot_frame` |
| 생성한 `Bullet` | 포구 좌표·속도·피해·수명·충돌 반지름·진영 |

## 예시: 트윈을 한 번 클릭

연사 강화가 없는 트윈, 탄약 제한 활성화·잔탄 120·발사 대기 0을 가정합니다. 프레임 F에 첫 탄을 쏘며 잔탄은 119가 되고, 두 번째 탄은 F+3에 예약합니다. 버튼을 놓아도 정상 진행 중이면 예약 탄이 나가 잔탄은 118이 됩니다.

3은 초가 아니라 게임 프레임입니다. FPS 60에서는 약 0.05초이며 메뉴에서는 시간이 멈춥니다. 재장전·진화·플레이어 사망 등의 취소 조건이 먼저 발생하면 남은 점사는 취소됩니다. 새로운 클릭을 무제한 예약해 쌓는 구조는 아닙니다.

실제 충돌 반지름은 포신 폭을 따르고, 화면은 작은 탄환에 한해 최소 4px 표시 폭을 적용합니다. 저격 계열 탄속은 종류별 설정에 있습니다.
