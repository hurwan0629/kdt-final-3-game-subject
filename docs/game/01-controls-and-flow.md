# 조작과 사용자 흐름

현재 게임은 **천체를 부수고 적과 싸우며 오래 생존하는 무한 전투**입니다. 스테이지 클리어나 스토리 진행은 없습니다. 아래 화면은 실제 게임 렌더러로 재현한 설명용 장면입니다.

## 먼저 조작법

| 입력 | 동작 | 적용되는 화면 |
|---|---|---|
| W / A / S / D | 위 / 왼쪽 / 아래 / 오른쪽 이동. 두 키로 대각선 이동 | 전투 |
| 마우스 이동 | 커서 방향으로 조준. 이동 방향과 독립적 | 전투 |
| 마우스 좌클릭 | 발사. 유지하면 발사 간격에 맞춰 연사 | 전투 |
| R | 2.5초 재장전 | 전투, 살아 있을 때 |
| L | 보상이 있으면 카드 창 열기 / 닫기 | 전투·카드 |
| 1 / 2 / 3 | 해당 보상 카드 선택 | 카드 |
| ESC / P | 설정 메뉴 열기 / 계속하기 | 전투·카드·설정 |
| F1 | 디버그 표시 켜기 / 끄기 | 카드가 닫힌 게임 화면 |
| N | 다음 맵으로 바꾸고 새 게임 | 카드가 닫힌 게임 화면 |
| ↑ / ↓ / Tab | 메뉴의 활성 버튼 사이 이동 | 메인·설정 |
| Enter / Space | 선택된 메뉴 버튼 실행 | 메인·설정 |
| Enter | 새 게임 | 게임 오버 |
| Q | 게임 종료 | 설정 메뉴 |
| 창 닫기 | 게임 종료 | 모든 화면 |

마우스 우클릭에는 현재 동작이 없습니다. 메뉴 버튼을 누른 클릭이 전투 발사로 이어지지 않도록, 다시 좌클릭하려면 버튼을 한 번 놓아야 합니다.

## 1. 시작: 메인 메뉴

![메인 메뉴: 세 버튼이 가운데에 배치되어 있다](assets/01-main-menu.png)

**무한 스테이지**를 누르면 새 판을 시작합니다. **스토리 모드**는 비활성이고 눌러도 진행하지 않습니다. **게임 나가기**는 프로그램을 종료합니다. 방향키로 이동할 때도 비활성 스토리 버튼은 건너뜁니다.

처음 시작은 기본 `drift` 맵입니다. 실행 명령에서 맵이나 지형 옵션을 지정했다면 그 조건으로 시작합니다.

## 2. 전투: 이동하고 조준하고 발사

![기본 전투 화면과 HUD](assets/02-playing.png)

WASD로 이동하면서 마우스로 다른 방향을 쏠 수 있습니다. 이동 키를 놓으면 관성으로 감속합니다. 화면 밖에서도 적과 천체는 움직이며, 카메라는 플레이어를 따라갑니다.

HUD에서 보는 정보는 다음과 같습니다.

| 위치 | 정보 |
|---|---|
| 왼쪽 위 | 점수, 적 처치 수, 게임 시간 |
| 그 아래 | 레벨, 직업, 다음 레벨까지 경험치, 미사용 보상 수 |
| 오른쪽 위 | 남은 탄창 / 최대 탄창, 재장전 남은 시간과 진행 바 |
| 아래 가운데 | 현재 / 최대 체력 |
| 화면 위쪽 가운데 | 레벨업 안내 또는 선택한 보상 적용 안내 |
| 화면 아래 | 조작 안내. 설정에서 끌 수 있음 |

레벨업 안내는 보상을 사용할 때까지 남습니다. 선택을 마친 보상 이름은 게임 시간 기준 약 3초 표시됩니다.

## 3. 탄약이 줄면 재장전

![R을 눌러 재장전을 시작한 화면](assets/03-reloading.png)

`R`을 누르면 **2.5초 후 탄창이 120발로 채워집니다.** 남은 탄약이 있어도 시작할 수 있으며, 예비 탄약과 재장전 횟수 제한은 없습니다. 재장전 중에는 이동·조준은 가능하고 발사는 막힙니다.

탄창이 이미 가득 찼거나 재장전 중이면 R을 눌러도 새 재장전을 시작하지 않습니다. 상세 규칙은 [전투와 재장전](02-combat-and-reload.md)에 있습니다.

## 4. 레벨업: 보상을 나중에 골라도 됨

![L로 연 무작위 보상 카드 세 장](assets/04-rewards.png)

점수로 경험치를 얻어 레벨을 올리면 선택권이 쌓입니다. **자동으로 카드 창이 열리지는 않습니다.** `L`을 눌러 세 장을 보고 `1·2·3` 중 하나를 선택합니다. 카드 그림을 마우스로 눌러 선택하는 기능은 현재 없습니다.

카드 창에서는 전투·회복·재장전 시간이 모두 멈춥니다. `L`로 닫았다 다시 열어도 같은 카드가 나옵니다. 선택권이 여러 개이면 한 장을 선택한 뒤 L을 다시 눌러 다음 보상을 고릅니다.

위 이미지는 190점을 넣어 Lv.3 상태를 만든 설명용 장면입니다. 실제 세 장은 매번 추첨되므로 이 조합으로 고정되지 않습니다. [전체 보상 목록](03-rewards.md)에는 모든 카드가 있습니다.

## 5. ESC: 일시정지와 설정

![설정 메뉴](assets/05-settings.png)

게임 중 `ESC` 또는 `P`를 누르면 이 메뉴가 열립니다. 보상 카드가 열린 상태에서도 설정 메뉴를 열 수 있고, 계속하기로 돌아오면 원래 카드 창이 유지됩니다.

현재 카드 화면 아래에는 `L / ESC: 닫기`라는 안내가 남아 있습니다. 실제 입력 동작은 **L은 카드 닫기, ESC는 설정 메뉴 열기**입니다. 안내 문구를 맞추는 것은 이후 수정할 부분입니다.

| 설정 | 기본 | 바뀌는 것 |
|---|---|---|
| 줌 배율 | 60% | 클릭할 때 75 → 100 → 45 → 60% 순환. 작은 값일수록 넓게 보임 |
| 조작 안내 | 켜짐 | 화면 아래 단축키 안내 표시 |
| 디버그 표시 | 꺼짐 | 관찰값, 적 경로·목표·플레이어 감지선 표시 |
| 창 전환 시 자동 일시정지 | 켜짐 | 창 포커스를 잃으면 설정 메뉴가 열림. 끄면 전투가 계속됨 |

**계속하기**는 현재 판으로 돌아갑니다. **새 게임**은 현재 맵에서 진행도를 초기화합니다. **메인 메뉴로** 돌아간 뒤 무한 스테이지를 다시 누르면 새 판을 시작합니다. **게임 나가기**는 종료입니다.

설정은 즉시 적용되고 같은 실행 안에서는 새 판에도 유지됩니다. 프로그램을 종료했다 켜면 기본값으로 돌아갑니다. 세이브 파일이나 설정 저장 파일은 없습니다.

## 6. 사망: 게임 오버

![게임 오버 화면](assets/06-game-over.png)

체력이 0이 되면 전투가 멈추고 최종 점수·처치 수·생존 시간이 표시됩니다. `Enter`로 새 판을 시작하거나 `ESC`로 메뉴를 엽니다. 부활이나 이전 판 이어하기는 없습니다. `R`은 재장전 키이므로 게임 오버를 다시 시작하지 않습니다.

## 읽으면서 판단할 부분

지금 보상과 설정은 별도 화면으로 분리되어 있습니다. 보상을 자동으로 열지, 여러 선택권을 한 번에 처리할지, 맵 선택을 N 대신 메뉴로 옮길지부터 판단하면 사용자 흐름을 정리하기 쉽습니다.
