# 맵과 지형

기본 월드는 134×101타일, 한 타일은 48px로 총 6432×4848px입니다. 기본 랜덤 지형은 8×8타일(384×384px) 블록 단위로 벽과 통로를 만듭니다. 실제 크기는 `GameConfig`와 `TerrainConfig`로 결정하며, 경험치용 별 조각과 행성도 등장합니다.

| 문자 | 기능 |
|---|---|
| `.` | 빈 공간 |
| `#` | 이동·시야·탄환을 막는 벽 |
| `~` | stage2에서 이동 가속도를 줄이는 중력장 |
| `+` | 기본은 벽, stage2에서 탄환으로 파괴 가능한 벽 |
| `P`, `E` | 시작 위치, 실제 지형은 빈칸 |

랜덤 지형은 블록 단위로 길을 연결하고 일부 연결 벽과 기둥을 제거합니다. 이름별 맵을 다른 월드 크기에 맞춰 생성하는 미로 경로는 벽 두께 4타일·주요 통로 6타일을 기본으로 사용합니다. 최대 선체 반경 96px의 시타델도 통과하도록 연결성을 확인합니다. 경로 탐색과 스폰은 실제 선체 반지름을 고려하며 벽과 직접 닿아도 피해는 없습니다.

`maps/`의 `drift`, `ring`, `belt`, `hello-world` 원본은 각각 60×45타일입니다. 로더는 원본 크기를 요청하면 파일을 읽고, 다른 크기를 요청하면 해당 이름의 고정 seed로 미로를 생성합니다. `--map belt`로 선택할 수 있습니다. N은 이름별 맵·빈 월드를 순환하지 않고 새 8×8 랜덤 블록 지형으로 새 게임을 시작합니다. `--random-map`, `--no-terrain`, `--stage2` 실행 옵션도 유지합니다.

위 이미지는 기존 문서용 예시이며 현재 생성 결과와 모양이 다를 수 있습니다. 텍스트 맵의 주석은 `;`로 시작하며 은신 문자 `*`는 지원하지 않습니다. 생성 과정과 벽 이미지 표현은 [[development/classes/Renderer#지형과 이미지|렌더러 설명]]과 [terrain.py](../../src/space_z/game/terrain.py)를 참고합니다.

오른쪽 아래 전체 미니맵은 진한 회색으로 벽을, 밝은 회색으로 이동 공간을 표시합니다. 플레이어 위치·방향만 표시하고 적은 표시하지 않습니다. 카메라 이동·줌·창 크기와 관계없이 전체 월드를 유지하며 벽 파괴도 반영합니다. 미니맵 위 클릭도 일반 화면과 같이 사격 입력으로 전달됩니다.
