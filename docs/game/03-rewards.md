# 레벨업과 보상 카드

점수만큼 경험치를 얻습니다. 레벨업마다 보상 선택권을 한 개 받고, L로 연 세 장 중 하나를 선택합니다. 레벨을 올리는 것만으로 체력이 회복되거나 능력치가 늘지는 않습니다. **카드를 선택해야 효과가 적용됩니다.**

## 경험치와 선택권

다음 레벨에 필요한 경험치는 `60 + (현재 레벨 - 1) × 40`입니다. 필요한 양을 빼고 남은 경험치는 다음 레벨에 이어집니다.

| 도달 레벨 | 직전 레벨에서 필요한 XP | 시작부터 누적 XP |
|---|---|---|
| 2 | 60 | 60 |
| 3 | 100 | 160 |
| 4 | 140 | 300 |
| 5 | 180 | 480 |
| 6 | 220 | 700 |

큰 점수를 한 번에 얻으면 여러 레벨을 올릴 수 있습니다. 예를 들어 기본 적 한 대를 처치해 200점을 얻으면 Lv.1에서 Lv.3이 되고, 남은 XP 40과 선택권 2개를 가집니다. 현재 별도의 최고 레벨 제한은 없습니다.

세 장은 선택 가능한 카드 중에서 **중복 없이** 추첨됩니다. 닫았다 다시 열어도 재추첨되지 않습니다. 카드를 선택하면 선택권 한 개를 사용하고 나머지 두 장은 버립니다. 다음 선택권을 열 때 새 조합을 뽑습니다.

## 일반 카드: 7개

| 카드 | 분류 | 실제 효과 | 누적 방식 / 제한 |
|---|---|---|---|
| 화력 강화 | 강화 | 탄환 피해량 ×1.25 | 반복 선택 시 곱해서 증가 |
| 속사 장치 | 강화 | 발사 대기 설정 ×0.85 후 정수로 내림 | 최소 4프레임. 20 → 17 → 14 … |
| 추진기 강화 | 능력치 | 이동 가속도 ×1.15 | 반복 선택 시 곱해서 증가 |
| 선체 확장 | 능력치 | 최대 체력 +25, 현재 체력 +25 | 현재 체력은 최대치까지만 증가 |
| 긴급 수리 | 회복 | 최대 체력의 60%만큼 즉시 회복 | 최대 체력 초과 불가 |
| 자가 수리 | 회복 | 초당 자동 회복량 +1.5 | 반복해서 더해짐. 피격 후 대기 4초 유지 |
| 고속 탄환 | 강화 | 탄속 ×1.20, 수명 배율 ×1.15 | 반복 선택 시 곱해서 증가. 실제 수명은 정수 프레임 |

기본 탄환 피해 7에서 화력 강화를 두 번 고르면 `7 × 1.25 × 1.25 = 10.9375`가 됩니다. 기본 회복은 초당 3이고, 자가 수리를 두 번 고르면 초당 6이 됩니다.

추진기 강화는 가속도와 결과적인 최고 속도를 함께 올립니다. 체력·화력·이동·탄속 강화에는 현재 별도의 상한이 없고, 속사 장치만 최소 대기 값이 있습니다. 체력이 가득 차도 긴급 수리 카드가 추첨될 수 있습니다.

**탄약 보급 카드는 현재 없습니다.** 탄약은 R 재장전으로 무제한 보충합니다.

## 전직 카드: 3개

전직 카드는 **Lv.3 이상이고 아직 기본 우주선일 때** 추첨 대상에 들어갑니다. 조건을 만족해도 세 장에 반드시 나오지는 않습니다. 한 번 전직하면 다른 전직 카드는 더 이상 추첨되지 않습니다.

| 전직 | 적용되는 효과 | 플레이 변화 |
|---|---|---|
| 정찰선 전직 | 가속도 ×1.35, 탄속 ×1.20 | 더 빠르게 움직이고 빠른 탄환을 사용 |
| 포격선 전직 | 3방향 동시 발사, 각 탄환 피해 배율 ×0.80 | 조준 방향과 양쪽 약 11.5°로 발사. 넓게 쏘지만 탄약 사용 증가 |
| 수호선 전직 | 최대 체력 +60, 즉시 완전 회복, 초당 자동 회복 +1.5 | 더 큰 체력과 회복량 |

이전 일반 카드 강화는 전직 후에도 남습니다. 포격선의 ×0.80도 이전 피해 배율에 곱해집니다. 선체 확장·자가 수리와 수호선의 효과는 함께 누적됩니다.

포격선은 발사 한 번에 최대 3발을 쓰고, 마지막 탄약이 1~2발이면 남은 만큼만 발사합니다. 현재 2발만 남았을 때는 왼쪽과 중앙 탄환이 나갑니다. 직업 이름과 공격은 바뀌지만, 직업별 별도 선체 이미지·추가 스킬·후속 전직은 없습니다.

## 보상의 생명주기

새 게임이나 맵 변경은 레벨·경험치·미사용 선택권·카드·강화·직업을 모두 초기화합니다. 메뉴로 돌아가도 현재 판을 저장하지 않으며, 다시 무한 스테이지를 시작하면 초기화됩니다. 사망한 상태에서는 남은 선택권을 사용할 수 없습니다.

## 수정 판단

첫 적 처치만으로 Lv.3에 도달하므로 전직이 빨리 열립니다. 성장 속도가 적당한지, 전직을 확정 선택으로 바꿀지, 무제한 곱셈 강화에 상한을 둘지, 회복이 필요 없을 때 회복 카드도 나오게 둘지 판단할 수 있습니다.
