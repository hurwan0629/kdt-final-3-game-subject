# 맵과 지형

각 맵은 60×45칸 전체 월드이고 한 칸은 48px입니다. 기본 크기는 2880×2160이며 이전의 3×3 반복 배치를 없앴습니다. 은신 지형은 제거했고, 작은 벽 조각 대신 두꺼운 긴 벽과 열린 교차 통로로 가벼운 미로를 만듭니다. 경험치용 별 조각과 행성은 그대로 등장합니다.

| 문자 | 기능 |
|---|---|
| `.` | 빈 공간 |
| `#` | 이동·시야·탄환을 막는 벽 |
| `~` | stage2에서 이동 가속도를 줄이는 중력장 |
| `+` | 기본은 벽, stage2에서 탄환으로 파괴 가능한 벽 |
| `P`, `E` | 시작 위치, 실제 지형은 빈칸 |

벽 두께는 기본 4칸(192px), 주요 통로는 6칸(288px)입니다. 현재 가장 큰 시타델의 반경은 67.2px입니다. 맵 연결성 검사는 기존 96px 기준을 유지해 여유를 확보합니다. 경로 탐색과 스폰은 점이 아닌 실제 선체 반지름을 고려합니다. 벽과 직접 닿아도 피해는 없습니다.

`drift`, `ring`, `belt`, `hello-world`는 각각 다른 연결된 미로입니다. N으로 순환하고 이후 랜덤 맵과 빈 월드로 바뀝니다. 맵 변경은 새 게임입니다. `--map belt`, `--random-map`, `--no-terrain`, `--stage2`로 실행 조건을 고릅니다.

랜덤 맵은 길고 두꺼운 벽을 배치하고 통로 연결성을 검증합니다. 텍스트 맵의 주석은 `;`로 시작하며 은신 문자 `*`는 더 이상 지원하지 않습니다.

오른쪽 아래 전체 미니맵은 진한 회색으로 벽을, 밝은 회색으로 이동 공간을 표시합니다. 플레이어 위치·방향만 표시하고 적은 표시하지 않습니다. 카메라 이동·줌·창 크기와 관계없이 전체 월드를 유지하며 벽 파괴도 반영합니다. 미니맵 위 클릭은 사격으로 전달하지 않습니다.
