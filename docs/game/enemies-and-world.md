# 적 AI와 월드

적은 감지 거리와 시야선을 확인해 플레이어 또는 천체를 목표로 선택합니다. 은신 지형과 은신 판정은 없습니다. 벽은 시야와 탄환을 막으며, 목표까지 바로 이동할 수 없으면 선체 크기를 고려하는 A* 경로를 찾습니다.

적은 플레이어를 놓치면 마지막으로 확인한 위치를 기억합니다. 반응 주기·조준 오차·거리·재등장 시간은 `EnemyAIConfig`에서 조절합니다. 플레이어가 진화를 확정하면 적도 같은 단계의 기체 중 하나를 추첨하며 같은 계열을 고를 필요는 없습니다. 이미지는 같은 우주선 PNG의 선체 색을 바꿔 표시합니다. 자세한 갱신 과정은 [[development/classes/EnemyController#적 갱신|적 성장·진화]]에서 확인할 수 있습니다.

천체를 부수거나 적을 처치하면 점수와 경험치를 얻습니다. 기본 설정은 적 9대와 천체 30개를 유지하며 죽은 적과 부족한 천체가 다시 등장합니다. 개체 수는 `GameConfig`로 조절합니다.
