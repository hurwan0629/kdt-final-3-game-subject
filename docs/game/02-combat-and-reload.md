# 전투·체력·탄약·재장전

플레이어는 우주선 한 대로 시작합니다. 기본 공격은 단발 탄환이고, 전직·강화 카드를 고르면 화력이나 움직임이 누적해서 달라집니다. 아래 수치는 **보상을 고르기 전, 60fps 기준**입니다.

## 기본 플레이어

| 항목 | 기본값 | 플레이에서의 의미 |
|---|---|---|
| 최대 / 시작 체력 | 100 / 100 | 0이면 게임 오버 |
| 충돌 반지름 | 22px | 그림 전체가 아니라 원 형태로 충돌 판정 |
| 가속도 | 프레임당 0.35 | 키를 누르면 점점 속도가 붙음 |
| 속도 유지 계수 | 매 프레임 0.90 | 놓으면 점점 감속 |
| 빈 공간 최대 속도 | 약 3.5px/프레임, 210px/초 | 대각선도 같은 속도 크기 |
| 피격 후 회복 대기 | 240프레임, 4초 | 다시 맞으면 대기 시간이 다시 시작됨 |
| 기본 자동 회복 | 0.05/프레임, 초당 3 | 최대 체력까지만 회복 |

마우스 조준은 커서 방향으로 즉시 바뀝니다. 사람의 조준에는 적 AI의 느린 회전 규칙이 적용되지 않습니다. 현재 그림에서는 선체와 포구가 같은 방향을 사용하므로, 조준하면 우주선 모양도 함께 회전합니다.

## 탄환과 발사

| 항목 | 기본값 |
|---|---|
| 탄환 피해 | 7 |
| 탄환 속도 | 9px/프레임, 540px/초 |
| 탄환 반지름 | 6px |
| 탄환 수명 | 70프레임, 약 1.17초 |
| 생성 위치 | 선체 중심에서 조준 방향으로 38px 앞 |
| 발사 대기 설정 | 20프레임 |
| 탄창 / 예비 탄약 | 120발 / 무제한 |

대기 설정은 20프레임이지만 현재 코드에서는 0이 되는 프레임을 지나 다음 프레임에 쏩니다. 좌클릭을 계속 유지할 때 실제 발사 간격은 **21프레임, 약 0.35초**입니다. 사거리는 탄속과 수명으로 제한되고, 벽이나 목표에 먼저 맞으면 더 짧아집니다.

기본 탄환은 한 대상을 맞히면 사라집니다. 레이저 전직은 관통, 대포·폭탄은 범위 폭발이 있습니다. 플레이어 공격은 적과 천체를, 적 탄환은 플레이어와 천체를 맞힙니다. 적끼리 탄환으로 피해를 주지는 않습니다. 성운·소행성은 탄환과 레이저를 막습니다.

## 재장전

기본 R 재장전은 150게임 프레임, 2.5초입니다. 탄창 확장은 용량을 늘리고 재장전 장치는 시간을 줄여 최소 0.75초까지 강화합니다. 재장전 횟수 제한이나 예비 탄약 소모는 없습니다.

| 상황 | 처리 |
|---|---|
| 재장전 중 이동·조준 | 가능 |
| 재장전 중 주무기 발사 | 불가능. 폭탄·대시는 별도 사용 가능 |
| 재장전 중 R 반복 | 타이머를 다시 시작하지 않음 |
| 가득 찬 탄창에서 R | 시작하지 않음 |
| 설정 메뉴 열기 | 타이머도 멈춤. HUD 강화·전직 선택은 시간이 계속됨 |
| 재장전 중 사망 | 게임 오버. 부활하거나 재장전으로 회복하지 않음 |
| 새 판 시작 | 탄창 120발, 재장전 타이머 초기화 |

재장전 완료 프레임까지 발사는 막히고, 그 다음 프레임부터 발사할 수 있습니다. 자동 재장전은 없으므로 탄창이 0이면 직접 R을 눌러야 합니다.

## 접촉 피해와 회복

천체와 우주선이 닿으면 서로 밀려나고, 닿아 있는 프레임마다 양쪽에 기본 0.6 피해가 들어갑니다. 플레이어와 적이 닿아도 서로 같은 접촉 피해를 받습니다. 적끼리는 서로 밀어내지만 이 접촉으로 체력을 깎지는 않습니다.

벽에 부딪히는 것 자체는 체력을 깎지 않습니다. 회복은 피격이 없었던 시간이 4초 이상일 때 시작하고, 자가 수리는 회복량만 늘립니다. 대시 중에는 피해를 받지 않지만 벽은 통과하지 못합니다. 사망한 플레이어는 회복이나 강화로 되살릴 수 없습니다.

## 점수의 출처

플레이어가 천체를 마지막으로 파괴하거나 적을 처치하면 점수를 받습니다. 피해만 주는 동안은 게임 점수가 올라가지 않습니다. 적이 대신 천체를 부쉈다면 플레이어에게 점수가 들어오지 않습니다. 소행성 벽 파괴에는 점수·경험치가 없습니다.

| 대상 | 파괴 / 처치 점수 |
|---|---|
| 별 조각 | 10 |
| 작은 암석 행성 | 25 |
| 고리 행성 | 130 |
| 적 우주선 | 200 |

사람 플레이에서는 점수만큼 경험치를 받습니다. 게임 시간은 설정 메뉴에서 멈추고 HUD 보상 선택 중에는 계속됩니다.

## 수정 판단

현재 재장전의 제약은 2.5초 발사 중단뿐입니다. 탄창 용량을 낮출지, 재장전 중 이동도 느리게 할지, 전직별 탄약 효율을 다르게 할지 판단하면 전투 리듬이 달라집니다. 체력 회복 속도와 접촉 피해는 장시간 생존 난이도에 직접 영향을 줍니다.

구현 위치: `config.py::GameConfig`, `game_core.py::_fire`, `request_reload`, `_collide_bodies`, `_regen_player`.
