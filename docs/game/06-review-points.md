# 현재 제한과 수정 판단

앞 문서는 현재 있는 기능을 설명했습니다. 여기서는 **무엇을 더 만들거나 바꿀지 판단할 때 필요한 빈 부분**을 모았습니다. 구현 제안이 확정되었다는 뜻은 아닙니다.

## 현재 없는 기능

| 영역 | 현재 상태 |
|---|---|
| 스토리 | 버튼만 있고 비활성. 대사·미션·스토리 진행 없음 |
| 스테이지 | 이름은 무한 스테이지지만 라운드 번호·웨이브·클리어·자동 난이도 상승 없음 |
| 저장 | 이어하기·세이브·기록 보관·설정 저장 없음 |
| 성장 | 일반 능력치 8종 중 3개 제시, 4계열·8진화·고유 스킬 8개. 장비·상점·영구 성장 없음 |
| 월드 상호작용 | 이동·숨기·감속·벽 파괴. 문·포탈·퀘스트·줍는 아이템 없음 |
| 전투 | 다중 발사·레일건·기뢰·유도탄·반동·돌격·고유 스킬이 있음. 별도 방어막 자원 없음 |
| 표현 | PNG 배경·우주선·지형·탄알과 피격·등장·폭발 연출. 음악·효과음 없음 |
| 멀티플레이 | 플레이어 한 명과 규칙 기반 적. 다른 사용자 접속 없음 |

우주선 주변 원은 충돌 범위를 표현한 그림입니다. 별도로 소모되는 방어막 자원은 아닙니다. 체력·탄약·경험치·점수·처치 수가 현재 주요 자원입니다.

## 먼저 판단하기 좋은 지점

| 판단할 내용 | 지금의 동작 | 바꾸면 영향을 받는 것 |
|---|---|---|
| 성장 속도 | 일반 강화, Lv.10·20…에 전직·스킬 | 첫 전직까지의 시간 |
| 강화 상한 | 연사·재장전 외 대부분 상한 없음 | 장기 생존 난이도·탄속·이동 성능 |
| 전직 선택 | Lv.10의 4계열 → Lv.20의 2진화 → Lv.30 고유 스킬, 이후 숙련 | 갈래별 성능·탄약 효율 |
| 보상 화면 | HUD에서 실시간 선택 | 플레이 도중 선택 위험·클릭 영역 |
| 재장전 부담 | 예비 탄약 무제한, 이동 가능, 2.5초 발사 중단 | 탄창 크기와 다중 발사 계열의 가치 |
| 회복의 의미 | 선체 강화 시 +25 회복·피격 후 자동 회복 | 실수의 비용·생존 난이도 |
| 적 성장 | 고정 성능의 9대가 다시 등장 | 장기 플레이의 목표와 긴장감 |
| 맵 다양성 | 한 템플릿을 3×3 반복 | 탐색 가치·동선 기억·구역 구분 |
| 지형 기능 접근 | stage2는 실행 옵션 | 일반 사용자가 감속·파괴를 발견할 수 있는지 |
| 맵 선택 | 실행 옵션이나 N으로 새 판 | 메뉴에서 맵을 고르고 싶은지 |
| 설정 유지 | 실행 중에만 유지 | 다시 실행할 때의 편의 |
| 점수 기록 | 게임 오버 화면에만 표시 | 판이 끝난 뒤 남는 목표 |

## 세부 구현에서 알고 있으면 좋은 점

**화력 강화는 주무기·고유 스킬·돌격선 충돌 공격에 적용됩니다.** 일반 우주선의 몸체 접촉 피해는 그대로입니다. 기동 추진기는 가속도 배율을 바꾸고, 자가 수리는 회복 대기를 없애지 않습니다.

**발사 대기 설정과 실제 연사 간격은 1프레임 차이**가 있습니다. 재장전·스킬 시간은 게임 프레임 기준이고 설정 메뉴에서만 멈춥니다. HUD 강화·전직 선택은 전투 시간을 멈추지 않습니다.

**고속 이동의 충돌 처리도 바뀌었습니다.** 탄환은 이동 구간의 벽과 대상 중 먼저 맞은 곳을 검사하고, 대시·빠른 이동은 여러 구간으로 나누어 벽 충돌을 처리합니다. 레이저는 직선 구간과 벽 차단을 별도로 검사합니다.

**새 판에는 이전 보상이 없습니다.** 새 게임·맵 변경·메인 메뉴에서 다시 시작하기가 모두 초기화를 일으킵니다. 판 바깥에서 영구적으로 남는 강화는 없습니다.
