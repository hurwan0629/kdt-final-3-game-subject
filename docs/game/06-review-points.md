# 현재 제한과 검토 사항

현재는 무한 스테이지 한 판을 플레이합니다. 스토리·웨이브·클리어·세이브·멀티플레이·음악은 없습니다. 새 게임 시 성장과 포인트가 초기화됩니다.

성장은 고정 5종 스탯과 21종 진화 트리입니다. 기존 액티브 스킬·기뢰·유도탄·램 전직은 새 트리로 교체했습니다. 방어 기체는 별도 방어막 자원 대신 큰 체력·선체·피해 감소를 사용합니다.

각 기체의 피해·발사 간격·사거리과 가디언 체력은 `progression.py`에 모았습니다. 제공 PNG는 그대로 사용하고 기능은 요청한 포신 수·방향 명세를 따릅니다. 일부 원본 그림의 포신 표현은 기능 명세와 다를 수 있습니다.

장기 플레이 밸런스는 일반 강화 누적, 대형 기체의 피탄 면적, 다연장 탄약 효율을 중심으로 검토하면 됩니다. 발사 대기 카운터 때문에 실제 연사 주기는 표시된 대기 값보다 1프레임 길 수 있습니다.
