# 현재 제한과 수정 판단

앞 문서는 현재 있는 기능을 설명했습니다. 여기서는 **무엇을 더 만들거나 바꿀지 판단할 때 필요한 빈 부분**을 모았습니다. 구현 제안이 확정되었다는 뜻은 아닙니다.

## 현재 없는 기능

| 영역 | 현재 상태 |
|---|---|
| 스토리 | 버튼만 있고 비활성. 대사·미션·스토리 진행 없음 |
| 스테이지 | 이름은 무한 스테이지지만 라운드 번호·웨이브·클리어·자동 난이도 상승 없음 |
| 저장 | 이어하기·세이브·기록 보관·설정 저장 없음 |
| 성장 | 카드 10개, 전직 3개. 직업별 스킬·후속 전직·장비·상점 없음 |
| 월드 상호작용 | 이동·숨기·감속·벽 파괴. 문·포탈·퀘스트·줍는 아이템 없음 |
| 전투 | 기본 탄환과 3방향 발사. 대시·회피 무적·방어막 수치·관통·폭발 없음 |
| 표현 | 기본 그래픽과 피격·등장·폭발 연출. 음악·효과음·직업별 별도 선체 없음 |
| 멀티플레이 | 플레이어 한 명과 규칙 기반 적. 다른 사용자 접속 없음 |

우주선 주변 원은 충돌 범위를 표현한 그림입니다. 별도로 소모되는 방어막 자원은 아닙니다. 체력·탄약·경험치·점수·처치 수가 현재 주요 자원입니다.

## 먼저 판단하기 좋은 지점

| 판단할 내용 | 지금의 동작 | 바꾸면 영향을 받는 것 |
|---|---|---|
| 성장 속도 | 적 한 대로 Lv.3 가능 | 초반 전직 시점·플레이 리듬 |
| 강화 상한 | 속사 외 대부분 상한 없음 | 장기 생존 난이도·탄속·이동 성능 |
| 전직 선택 | 세 장의 무작위 카드에 포함 | 원하는 직업에 도달할 확률 |
| 보상 화면 | L로 직접 열고 한 장씩 처리 | 반복 입력 수·전투 중단 횟수 |
| 재장전 부담 | 예비 탄약 무제한, 이동 가능, 2.5초 발사 중단 | 탄창 크기와 포격선의 가치 |
| 회복의 의미 | 즉시 회복 카드·피격 후 자동 회복 | 실수의 비용·생존 난이도 |
| 적 성장 | 고정 성능의 9대가 다시 등장 | 장기 플레이의 목표와 긴장감 |
| 맵 다양성 | 한 템플릿을 3×3 반복 | 탐색 가치·동선 기억·구역 구분 |
| 지형 기능 접근 | stage2는 실행 옵션 | 일반 사용자가 감속·파괴를 발견할 수 있는지 |
| 맵 선택 | 실행 옵션이나 N으로 새 판 | 메뉴에서 맵을 고르고 싶은지 |
| 설정 유지 | 실행 중에만 유지 | 다시 실행할 때의 편의 |
| 카드 화면의 ESC 안내 | 화면은 닫기라고 표시하지만 실제로는 설정 메뉴를 엶 | 안내와 입력 동작 일치 |
| 점수 기록 | 게임 오버 화면에만 표시 | 판이 끝난 뒤 남는 목표 |

## 세부 구현에서 알고 있으면 좋은 점

**화력 강화는 탄환에만 적용됩니다.** 몸체 접촉 피해는 그대로입니다. 추진기 강화는 단순 최고 속도 수치가 아니라 가속도 배율을 바꾸고, 자가 수리는 회복 대기를 없애지 않습니다. 전직 설명을 바꿀 때 이 차이를 같이 보면 됩니다.

**발사 대기 설정과 실제 연사 간격은 1프레임 차이**가 있습니다. 현재 코어가 대기를 0으로 만든 프레임에 바로 쏘지 않고 다음 프레임에 쏘기 때문입니다. 재장전 시간은 게임 프레임을 기준으로 하므로 메뉴·카드 창에서 멈춥니다.

**탄환 충돌은 이동 후 위치를 기준으로 합니다.** 이동한 선 전체를 검사하지 않아, 고속 탄환 강화를 많이 쌓으면 벽이나 대상을 건너뛸 가능성이 코드상 있습니다. 이 문서에서는 해당 현상의 재현 테스트를 추가하거나 규칙을 수정하지 않았습니다.

**새 판에는 이전 보상이 없습니다.** 새 게임·맵 변경·메인 메뉴에서 다시 시작하기가 모두 초기화를 일으킵니다. 판 바깥에서 영구적으로 남는 강화는 없습니다.
