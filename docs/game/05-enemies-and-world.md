# 적 AI와 월드

적은 감지 거리와 시야선을 확인해 플레이어 또는 천체를 목표로 선택합니다. 은신 지형과 은신 판정은 없습니다. 벽은 시야와 탄환을 막으며, 목표까지 바로 이동할 수 없으면 선체 크기를 고려하는 A* 경로를 찾습니다.

적은 플레이어를 놓치면 마지막 위치를 잠시 기억합니다. 반응 주기·조준 오차·거리·재등장 시간은 `EnemyAIConfig`에서 조절합니다. 적 기체 이미지는 기존 PNG를 사용하며 플레이어의 새 진화 트리와는 별도입니다.

천체를 부수거나 적을 처치하면 점수와 경험치를 얻습니다. 기본 월드는 적 9대와 천체 72개를 유지하며 죽은 적과 부족한 천체가 다시 등장합니다. 경험치 오브젝트는 이번 맵 개편에서 제거하지 않았습니다.
