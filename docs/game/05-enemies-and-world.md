# 적 AI와 월드 유지

월드에는 기본 **적 우주선 9대와 천체 72개**가 있습니다. 천체를 부수면 바로 새 천체가 생기고, 적을 처치하면 잠시 뒤 다시 등장합니다. 전부 처치해 판을 끝내는 방식이 아니라 계속 자원을 얻고 싸우는 구조입니다.

## 적 우주선

| 항목 | 기본값 |
|---|---|
| 체력 | 60 |
| 처치 점수 | 200 |
| 재등장 대기 | 300프레임, 5게임초 |
| 이동 가속 배율 | 플레이어 기본 가속도의 80% |
| 회전 속도 | 공통 회전 속도의 70% |
| 탄환 피해 | 7, 플레이어 기본 탄환과 동일 |
| 발사 대기 설정 | 36프레임. 연속 발사 시 실제 간격은 37프레임 |
| 탄약 | 제한 없음 |

플레이어가 성장해도 적의 체력·피해·이동·수는 자동으로 성장하지 않습니다. 적에게 자동 회복이나 전직은 없습니다. 사망한 적은 같은 적 객체를 다시 사용해 체력을 가득 채우고 새 위치에 등장합니다.

## 적이 행동하는 흐름

1. **플레이어를 볼 수 있는지 검사.** 450px 이내, 플레이어가 구름 밖, 벽에 가리지 않은 경우입니다.
2. **목표 선택.** 보이는 플레이어와 가장 가까운 천체를 거리로 비교합니다. 플레이어 거리는 1.6으로 나눠 계산해 더 우선하기 쉽게 만듭니다. 목표는 기본 20프레임마다 재검토합니다.
3. **이동.** 직접 보이면 거리를 유지하며 접근·후퇴·옆으로 이동합니다. 플레이어와는 약 230px, 천체와는 약 140px를 유지하려고 합니다.
4. **길 찾기.** 목표가 벽 너머에 있으면 타일 기준 8방향 A* 경로를 따라갑니다. 벽 모서리를 대각선으로 통과하지 못합니다. 경로는 기본 20프레임마다 갱신합니다.
5. **조준과 발사.** 목표 방향으로 돌아가고, 시야와 조준 조건이 맞으면 쏩니다. 조준에는 표준편차 12°의 무작위 오차가 있습니다. 허용 조준 차이는 15°입니다.

목표가 없으면 무작위 이동 방향을 사용합니다. 플레이어를 쫓던 적이 시야를 잃으면 마지막 위치를 최대 약 2초 기억하고 그곳을 찾아갑니다. 단순히 보였던 모든 플레이어 위치를 항상 기억하는 것은 아니며, 플레이어 추적 중에 기억을 갱신합니다.

길 찾기는 탐색량 제한이 있어 실패할 수 있습니다. 경로가 없으면 현재 코드에서는 목표 방향으로 이동을 시도합니다. 벽을 무조건 통과하는 것은 아니고, 지형 충돌이 계속 적용됩니다.

## 적의 스폰

맵 E 위치 중 플레이어와 300px 이상 떨어져 있고 다른 적과 겹치지 않는 곳을 먼저 고릅니다. 적당한 E가 없으면 빈 타일에서 랜덤 위치를 찾습니다. 최대 20회 시도하는 방식이므로 거리 조건이 항상 엄격하게 보장되지는 않습니다.

적은 맵의 표시 개수와 관계없이 설정된 9대까지 생성됩니다. E는 스폰 후보이지 반드시 한 대씩 차지하는 자리가 아닙니다. 재등장 대기는 설정 메뉴에서 멈추고, HUD 보상 선택 중에는 계속됩니다.

## 천체: 경험치를 얻는 대상

| 코드 종류 | 화면 표현 | 체력 | 점수 / XP | 반지름 | 생성 가중치 |
|---|---|---|---|---|---|
| `square` | 별 조각 | 10 | 10 | 14px | 65% |
| `triangle` | 작은 암석 행성 | 25 | 25 | 16px | 27% |
| `pentagon` | 고리 행성 | 100 | 130 | 26px | 8% |

위 가중치는 새 천체를 하나 생성할 때의 확률입니다. 항상 72개 중 정확히 해당 비율을 유지하는 것은 아닙니다. 천체는 약하게 표류하고 회전하며, 월드 경계·벽에서 튕기거나 밀려납니다.

플레이어·적과 충분히 떨어진 빈 타일에 생성하려고 시도합니다. 큰 고리 행성은 주변이 열린 타일을 우선 사용합니다. 천체끼리 겹치지 않도록 검사하거나 서로 밀어내는 별도 충돌은 없습니다.

적도 천체를 부술 수 있습니다. 부족한 개수는 한 게임 프레임이 끝나기 전에 다시 채우므로, 천체를 전부 정리해 안전한 맵을 만드는 방식은 아닙니다.

## 카메라와 화면 밖의 세계

기본 화면은 960×720이고 60% 줌에서는 약 1600×1200 월드 영역을 봅니다. 가장자리에서는 화면이 월드 밖으로 나가지 않도록 카메라가 멈춥니다. 월드가 화면 영역보다 작으면 중앙에 배치합니다.

렌더러는 멀리 있는 물체의 그림을 일부 생략하지만 코어는 계속 진행합니다. **화면에서 사라진 적이 멈추거나 없어지는 것은 아닙니다.** AI의 감지 거리와 카메라가 보여주는 범위도 서로 다른 값입니다.

배경 별, 성운, 선체·천체 스프라이트는 Pygame에서 만들어 그립니다. 등장·피격·폭발 연출은 게임 상태와 분리되어 있고, 생존 결과나 난수 추첨을 바꾸지 않습니다. 현재 음악·효과음은 없습니다.

## 수정 판단

오래 살아도 적은 같은 난이도로 반복 등장합니다. 시간이 지나면서 적을 강하게 할지, 적 종류를 나눌지, 천체 보충에 지연을 줄지, 적의 스폰 거리를 더 강하게 보장할지 판단하면 무한 스테이지의 성격을 정할 수 있습니다.

구현 위치: `EnemyAIConfig`, `SHAPE_TYPES`, `GameCore._enemy_ai`, `_respawn_enemy`, `_make_shape`, `Renderer`.
