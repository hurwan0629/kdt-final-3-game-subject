# 현재 제한과 검토 사항

현재는 무한 스테이지 한 판을 플레이합니다. 스토리·웨이브·클리어·세이브·멀티플레이·음악은 없습니다. 새 게임 시 성장과 포인트가 초기화됩니다.

성장은 고정 5종 스탯과 21종 진화 트리입니다. 기존 액티브 스킬·기뢰·유도탄·램 전직은 새 트리로 교체했습니다. 방어 기체는 별도 방어막 자원 대신 큰 체력·선체·피해 감소를 사용합니다.

각 기체의 피해·발사 간격·사거리과 가디언 체력은 `src/space_z/config/progression_definitions.py`에 모았습니다. 제공 PNG는 그대로 사용하고 기능은 요청한 포신 수·방향 명세를 따릅니다. 일부 원본 그림의 포신 표현은 기능 명세와 다를 수 있습니다.

장기 플레이 밸런스는 일반 강화 누적, 대형 기체의 피탄 면적, 다연장 탄약 효율을 중심으로 검토하면 됩니다. 발사 대기 카운터 때문에 실제 연사 주기는 표시된 대기 값보다 1프레임 길 수 있습니다.

## 기존 테스트 불일치와 캐시 검토

`test_difficulty_menu`의 키보드 선택 테스트 하나는 이전 이동 순서를 기대해 현재 동작과 불일치합니다. 현재 좌우는 난이도 행 안에서 이동하고, 상하는 난이도 행을 한 줄로 취급합니다. 이번 폴더 정리에서는 동작이나 기존 기대값을 변경하지 않았습니다.

렌더러의 지형 캐시 키는 `(id(terrain), terrain.version)`입니다. 객체 번호가 재사용되면 간헐적으로 이전 그림을 재사용할 수 있어 별도 검토가 필요합니다. 자세한 상태 위치는 [[development/classes/Renderer#지형과 이미지|지형 캐시 설명]]에서 확인합니다.
