# 강화학습 환경

사람 플레이와 학습 환경은 같은 `GameCore`를 사용하지만, **조작과 성장 조건은 다릅니다.** 현재 학습 환경은 기존의 단순한 27개 행동을 유지합니다.

## 사람 플레이와의 차이

| 항목 | 사람 플레이 | 기본 `TankEnv()` |
|---|---|---|
| 이동·조준 | WASD와 마우스 | 이동 9개 × 회전 3개 |
| 발사 | 좌클릭 | 자동 발사 |
| 레벨업·강화·전직·스킬 | 켜짐. HUD에서 선택 | 꺼짐 |
| 탄창·재장전 | 제한 탄창, R 재장전 | 탄약 무제한 |
| 시간 | 60 게임 프레임/초 | 한 행동을 기본 4프레임 적용 |
| 종료 | 사망, 메뉴에서 종료 | 사망 `terminated`, 3000 step에서 `truncated` |

화면 없는 학습에서는 `render_mode`를 지정하지 않습니다. `render_mode="human"`은 에이전트의 진행을 보여주는 용도이며, `main.py`의 사람용 메뉴·마우스 입력 루프를 실행하는 것은 아닙니다.

## 관찰값

기본 관찰은 `float32` 길이 **363**입니다. 벡터 121개와 플레이어 주변 11×11 타일의 2개 채널을 합칩니다.

| 부분 | 크기 | 내용 |
|---|---|---|
| 플레이어 | 9 | 위치·속도·체력 비율·조준 방향·발사 대기·숨기 여부 |
| 가까운 적 3개 | 24 | 존재·상대 위치·속도·체력·방향. 구름 안 적은 제외 |
| 가까운 천체 8개 | 48 | 존재·상대 위치·체력·점수·반지름 |
| 가까운 적 탄환 8개 | 40 | 존재·상대 위치·속도 |
| 주변 지형 | 242 | 벽과 가스 구름, 각 11×11 |

위치는 확장 월드 크기로 정규화합니다. 지형 격자는 우주선 방향에 맞춰 회전하지 않습니다. 부족한 대상은 0으로 채우고 존재 여부로 구분합니다. 선택적으로 레이 센서를 추가하거나, `obs_mode="dict"`로 벡터와 격자를 분리할 수 있습니다. 중력장·파괴 가능 벽 채널을 켜면 관찰 크기도 바뀝니다.

## 학습 보상

코어가 기록한 이벤트를 `compute_reward()`가 아래 계수로 합칩니다. **게임 점수·경험치, 레벨업 카드, 학습의 숫자 보상은 서로 다른 개념**입니다.

| 이벤트 | 기본 학습 보상 |
|---|---|
| 천체에 피해 | `0.002 × 실제 피해 × (천체 점수 / 최대 체력)` |
| 천체 파괴 | `0.01 × 천체 점수` |
| 적에게 피해 | `0.01 × 실제 피해` |
| 적 처치 | `+2` |
| 플레이어 피격 | `-0.02 × 실제 피해` |
| 사망 | `-5` |
| 한 step 경과 | `0` |

사망하면 종료되고, 사망하지 않아도 기본 3000 step에서 학습 에피소드가 잘립니다. 사람용 무한 스테이지에는 이 학습 step 제한을 적용하지 않습니다.

## 성장·재장전을 학습에 넣을 때

사용자 지정 `GameConfig`를 전달하면 그 설정을 그대로 씁니다. 기존 조건으로 학습하려면 `progression_enabled=False, limited_ammo=False`를 명시합니다.

성장을 켜면 `env.game.upgrade_stat(key)` / `choose_reward(index)`로 선택합니다. Lv.10은 4계열, Lv.20은 계열 내 2진화, Lv.30은 고유 스킬 자동 해금입니다. 탄약은 `request_reload()`, 스킬은 `request_skill()` 또는 코어 step의 `want_skill`로 요청합니다. `want_dash`는 해금한 워프·램 차지의 별도 입력입니다. 기본 27개 행동과 관찰에는 이 선택·스킬·성장 상태가 전부 포함되지는 않습니다. 같은 조건으로 학습하려면 행동·관찰 설계를 함께 확장해야 합니다.

`info`에는 기존 상태와 함께 `upgrade_points`, `special_reward_levels`, `stat_levels`, `special_levels`가 있습니다. 계열·해금 스킬·쿨다운·현재 강화 선택지는 `family`, `active_skill`, `skill_cooldown_seconds`, `stat_choices`로 확인합니다. `pending_rewards`는 일반 포인트와 전직 선택권을 합한 수입니다. 무제한 탄약일 때 `ammo`는 `None`입니다. 줌은 관찰값에 영향을 주지 않습니다.

맵·전투, 카드 추첨, 화면 연출은 난수 사용이 분리되어 있습니다. 같은 seed와 같은 행동·카드 선택을 사용하면 같은 코어 결과를 재현할 수 있습니다.
