# Space Skirmish: 강화학습용 탑뷰 우주선 슈팅 데모 (diep.io 축소판)

우주를 배경으로 우주선을 조종해 별 조각과 행성을 부수고 적 우주선과 싸우는 게임입니다. 사람이 WASD와 마우스로 플레이할 수 있고, 같은 게임을 화면 없이 강화학습 환경(Gymnasium 스타일)으로도 쓸 수 있는 구조의 데모입니다.

## 실행

```bash
pip install -r requirements.txt
python main.py                 # 사람 플레이 (랜덤 seed, 기본 맵 drift)
python main.py --seed 42       # seed 고정
python main.py --map belt      # 맵 선택 (drift / ring / belt)
python main.py --random-map    # 랜덤 맵 생성
python main.py --stage2        # 중력장 + 소행성(부서지는 벽) 켜기
python main.py --no-terrain    # 지형 없는 빈 우주
python random_agent_test.py    # headless 검사: 맵 검증 + 맵별 랜덤 실행 + 속도 + 재현성
```

## 확장 월드와 레벨업

- 실행하면 가운데에 **무한 스테이지 / 스토리 모드 / 게임 나가기** 버튼이 나타납니다. 무한 스테이지는 기존 게임을 시작하고, 스토리 모드는 준비 중인 비활성 버튼입니다. 클릭 또는 방향키·Enter로 선택할 수 있습니다.
- 화면은 960×720, 기본 월드는 2880×2160(60×45 타일)입니다. 기존 맵 템플릿을 가로·세로 3번 반복하여 연결하고, 중앙 구역에서 시작합니다. 랜덤 맵과 빈 경기장도 같은 크기로 생성합니다.
- 카메라는 플레이어를 중심으로 따라가며, 월드 가장자리에서는 화면이 밖으로 넘어가지 않도록 멈춥니다. 화면 밖에서도 전투와 이동은 계속됩니다.
- 기본 카메라 줌은 60%로, 한 화면에서 1600×1200 월드 영역을 보여줍니다. 우주선·지형·탄환을 함께 축소하며 HUD와 보상 카드는 원래 크기를 유지합니다.
- **WASD로 이동**, 커서 방향으로 포구를 조준하고 **마우스 왼쪽 버튼으로 발사**합니다. 두 이동 키를 함께 누르면 대각선으로 이동하고, 키를 놓으면 관성으로 감속합니다. 이동 방향과 조준 방향은 독립적이며, 좌클릭을 유지하면 발사 간격에 맞춰 연사합니다.
- **탄창은 120발, 예비 탄약은 무제한**입니다. `R`로 **2.5초 재장전**하면 탄창이 가득 찹니다. 발사된 탄환마다 1발을 쓰며 포격선의 3방향 발사는 최대 3발을 사용합니다. 남은 탄약이 있어도 재장전할 수 있고, 재장전 중에는 이동·조준은 가능하지만 발사는 불가능합니다. 재장전 중 `R`을 다시 눌러도 타이머를 다시 시작하지 않습니다.
- **`ESC` / `P`로 일시정지 설정 메뉴를 열거나 닫습니다.** 줌 배율(45 / 60 / 75 / 100%), 조작 안내, 디버그 표시, 창 전환 시 자동 일시정지를 변경할 수 있습니다. 메뉴의 계속하기·새 게임·메인 메뉴로·게임 나가기 버튼도 사용할 수 있습니다. 설정은 즉시 반영되고 이번 실행 동안 유지됩니다.
- 메뉴와 보상 창이 열린 동안 이동·발사·회복·적 행동 및 재장전 타이머가 멈춥니다. 기본적으로 창 포커스를 잃으면 설정 메뉴가 열리고, 돌아온 뒤 `ESC` / `P`로 재개합니다.
- 도형 파괴와 적 처치로 얻은 점수가 경험치가 됩니다. 첫 레벨업은 60 XP, 이후 필요 경험치는 레벨마다 40씩 증가합니다. 레벨을 올릴 때마다 카드 선택권이 1개 쌓입니다.
- **레벨업 안내가 나오면 `L` → 무작위 카드 3장 중 `1` / `2` / `3`으로 선택**합니다. `L`로 닫으면 보상과 카드는 유지되고, 다시 열어도 재추첨되지 않습니다. 보상이 여러 개면 선택 후 `L`을 다시 누릅니다. 카드 창에서 `ESC`를 누르면 설정 메뉴가 열리며, 계속하기로 돌아오면 카드 창도 유지됩니다.
- 화력·속사·이동·최대 체력·탄속/사거리 강화, 즉시 회복, 자동 회복 카드를 선택할 수 있습니다. 강화는 누적됩니다.
- **Lv.3부터 전직 카드**가 등장합니다. 정찰선은 이동/탄속 강화, 포격선은 3방향 동시 발사, 수호선은 체력/회복 강화입니다. 한 판에 한 번 전직할 수 있습니다.
- 설정 메뉴의 **새 게임**과 `N` 맵 변경은 레벨, 보상, 강화, 전직을 초기화합니다. 게임 오버 후 `Enter`로 새 게임을 시작할 수도 있습니다. `R`은 재장전만 수행합니다.

설정은 `GameConfig.world_scale`(1이면 원래 크기), `camera_zoom`(작을수록 줌아웃), `player_ammo`, `limited_ammo`, `reload_seconds`, `level_xp_base`, `level_xp_growth`, `num_shapes`, `num_enemies`에서 조절합니다. 카드 정의와 설명은 `progression.py`에 있습니다.

기본 `TankEnv()`는 기존 27개 이동/회전 행동과 자동 발사를 유지하고, 레벨업과 탄약 제한을 끕니다. 직접 `GameConfig`를 전달할 때도 같은 학습 방식이면 `progression_enabled=False, limited_ammo=False`를 지정하세요. 레벨업을 켠 환경에서는 `env.game.open_rewards()`와 `env.game.choose_reward(0~2)`로 별도 선택해야 하며, 카드 선택은 기본 행동 공간에 포함되지 않습니다. 관찰 벡터의 위치는 확장 월드 크기로 정규화하고, `info`에 `level`, `xp`, `pending_rewards`, `job`, `ammo`(무제한이면 `None`)를 제공합니다.

```bash
python -m unittest discover -s tests -v  # 월드/카메라/카드/입력 회귀 검증 (화면 없이 실행)
```

## 조작

| 키 | 동작 |
|---|---|
| W / A / S / D | 위 / 왼쪽 / 아래 / 오른쪽 이동 (조합하면 대각선 이동) |
| 마우스 커서 | 조준 |
| 마우스 왼쪽 버튼 | 발사 (유지하면 연사, 탄약 소모) |
| F1 | 디버그 표시 토글 (관찰값, 적 A* 경로, 시야선) |
| N | 다음 맵 (손맵들 → 랜덤 맵 → 빈 우주 순환) |
| P / ESC | 일시정지 설정 메뉴 열기 / 닫기 |
| L | 레벨업 보상 카드 열기 / 닫기 |
| 1 / 2 / 3 | 열린 보상 카드 선택 |
| R | 재장전 (2.5초, 예비 탄약 무제한) |
| Enter (게임 오버 후) | 새 게임 |
| Q (일시정지 중) / 창 닫기 | 종료 |

사람 플레이는 마우스로 조준·발사합니다. 강화학습의 기존 행동 공간은 이동 9방향 × 회전 3가지로 유지하며, 코어의 `step(action, want_fire=..., aim_position=(월드 x, 월드 y))`로 사람 입력을 전달합니다.

## 파일 구조

```
config.py            모든 설정값 (게임/지형/적 AI 난이도/관찰 N·M·K/보상 계수/frame_skip)
game_core.py         게임 규칙과 상태만 담당 (pygame 의존 없음, 1/60초 고정 간격)
terrain.py           타일맵: 맵 파싱·검증, 벽 충돌, 시야선/레이캐스트, A*, 랜덤 맵 생성 (pygame 의존 없음)
maps/*.txt           손으로 만든 맵 (drift, ring, belt)
progression.py       레벨업 보상 카드와 전직 이름
env.py               TankEnv: reset(seed) / step(action), 관찰·보상 계산
renderer.py          pygame으로 상태를 그리기만 함 (우주 컨셉 그래픽)
main.py              WASD 이동 + 마우스 조준·발사 + 키보드 메뉴 → game_core
menus.py             메인/설정 메뉴 버튼 정의와 클릭 영역
random_agent_test.py 랜덤 에이전트 속도 측정 + 같은 seed 재현성 확인
```

의존 방향은 `main → renderer, game_core`와 `env → game_core → terrain`입니다. `game_core`는 화면을 전혀 모르기 때문에 env는 화면 없이(headless) 돌아갑니다.

## 컨셉과 화면 표현

코드(게임 규칙)는 원래 이름을 그대로 쓰고, 화면에만 우주 컨셉을 입혔습니다. 그래서 강화학습 쪽 코드와 관찰은 그래픽과 상관없습니다.

| 게임 규칙 | 화면 표현 |
|---|---|
| 탱크 / 포신 | 우주선 / 기수 방향의 포 (움직이면 엔진 불꽃) |
| 도형 square / triangle / pentagon | 별 조각 / 작은 암석 행성 / 고리 행성 |
| 탄환 | 플라즈마 탄 |

## 지형

맵 템플릿은 48px 타일로 된 20×15 격자이고(`TerrainConfig.tile_size`), 기본 경기장은 템플릿을 확장한 60×45 격자입니다. 맵은 `maps/` 폴더의 텍스트 파일로 정의합니다.

| 문자 | 지형 (화면) | 효과 |
|---|---|---|
| `.` | 빈 우주 | |
| `#` | 성운 | 이동과 탄환을 막음. 우주선은 성운을 따라 미끄러지듯 이동 |
| `*` | 가스 구름 | 안에 있는 우주선은 상대에게 보이지 않음 (적 AI 감지 불가, 플레이어 관찰에서도 제외, 화면에서도 가려짐) |
| `~` | 중력장 (2단계) | 이동 가속 × 0.5 |
| `+` | 소행성 (2단계) | 체력 40. 탄환에 맞아 부서지면 빈 우주가 됨 |
| `P` / `E` | 플레이어 / 적 시작 위치 | |

맵은 답답하지 않도록 지형이 화면의 10% 안팎만 차지하게 만들었습니다. 랜덤 맵의 지형 밀도도 `random_*_density`로 조절할 수 있습니다.

- **기능 끄기:** 2단계 기능은 기본으로 꺼져 있습니다(`mud_enabled`, `breakable_enabled`). 끄면 `~`는 빈 우주, `+`는 일반 성운으로 취급합니다.
- **맵 선택:**
  - `enabled=False`이면 빈 경기장 모드입니다.
  - `random_map=True`이면 `reset`마다 랜덤 맵을 생성합니다. 모든 빈칸이 연결될 때까지(BFS 검증) 다시 생성합니다.
  - `map_pool=("drift", "belt")`처럼 지정하면 `reset`마다 seed로 맵을 고릅니다.
- **맵 검증:** 맵을 불러올 때 크기, 허용된 문자, `P`가 1개인지, 모든 빈칸이 연결됐는지 검사합니다. 잘못된 맵은 어느 줄이 문제인지 알려줍니다. `;`로 시작하는 줄은 주석입니다.

### 적 AI

- **감지:** 사거리 안, 가스 구름 밖, **시야선이 트였을 때**(사이에 성운 없음)만 플레이어를 봅니다.
- **목표:** 보이는 플레이어와 가장 가까운 천체(도형)를 가중 거리로 비교해 고릅니다.
- **추격:** 쫓던 플레이어를 놓치면 마지막으로 본 위치를 2초 동안 기억하고 그곳으로 갑니다.
- **경로:** 목표가 직접 안 보이면 8방향 **A\***로 경로를 찾아 따라갑니다(성운 모서리 대각선 통과 금지).
- **발사:** 시야선이 트였을 때만 쏩니다.

## 행동 (Discrete 27)

`action = move * 3 + rot` 이며, `encode_action(move, rot)` / `decode_action(action)`로 변환합니다.

- move: 0=정지, 1=↑, 2=↗, 3=→, 4=↘, 5=↓, 6=↙, 7=←, 8=↖
- rot: 0=유지, 1=왼쪽, 2=오른쪽

규칙 기반 적 AI도 같은 8방향 이동과 회전 규칙을 따릅니다.

## 관찰 (float32, 기본 길이 363 = 벡터 121 + 격자 2×11×11)

위치는 경기장 크기로 정규화합니다. 각 목록은 가까운 순서로 정렬하고, 대상이 부족하면 0으로 채우며 `exists=0`이 됩니다.

| 블록 | 필드 | 크기 |
|---|---|---|
| 내 탱크 | x, y, vx, vy, hp, sin θ, cos θ, 발사 대기 진행도, 수풀 안 여부 | 9 |
| 적 탱크 ×N(3) | exists, dx, dy, vx, vy, hp, sin, cos (수풀에 숨은 적은 제외) | 24 |
| 도형 ×M(8) | exists, dx, dy, hp, 점수, 반지름 | 48 |
| 적 탄환 ×K(8) | exists, dx, dy, vx, vy | 40 |
| 레이캐스트 (선택) | `n_rays`개 방향의 가장 가까운 벽까지 거리 (기본 0 = 끔) | n_rays |
| 지형 격자 | 내 칸 중심 11×11 타일, 지형 종류별 0/1 채널 (벽, 수풀 / 2단계를 켜면 + 진흙, 부서지는 벽). 맵 바깥은 벽 | C×11×11 |

- **관찰 형식:** `ObsConfig(obs_mode="dict")`로 바꾸면 `{"vector": (121,), "grid": (C, 11, 11)}` 형태로 받습니다. CNN을 쓸 때 편합니다.
- **빈 경기장 모드에서도** 격자 채널은 그대로 두기 때문에 관찰 크기가 바뀌지 않습니다.

## 보상 (`config.RewardConfig`)

| 이벤트 | 값 |
|---|---|
| 도형 데미지 | +0.002 × 데미지 × (점수 / 최대체력) |
| 도형 파괴 | +0.01 × 점수 |
| 적 데미지 | +0.01 × 데미지 |
| 적 처치 | +2.0 |
| 피격 | −0.02 × 받은 데미지 |
| 사망 | −5.0 → `terminated` |
| step 수 초과 (3000) | `truncated` |

`game_core`는 이벤트만 기록합니다. 보상으로 바꾸는 계산은 `env.compute_reward`에서 하므로, 보상 설계를 바꿀 때 게임 규칙을 건드릴 필요가 없습니다.

## 강화학습에서 쓰는 법

```python
from env import TankEnv
from config import EnvConfig, ObsConfig

env = TankEnv(env_config=EnvConfig(frame_skip=4, max_steps=3000), obs_config=ObsConfig(n_shapes=6))
obs, info = env.reset(seed=0)
obs, reward, terminated, truncated, info = env.step(env.action_space.sample())
```

- gymnasium이 설치되어 있으면 `gymnasium.Env`를 상속하고 `spaces`를 그대로 제공합니다. 그래서 stable-baselines3 같은 라이브러리에 바로 넣을 수 있습니다.
- `TankEnv(render_mode="human")`으로 만들면 학습된 에이전트가 플레이하는 화면을 볼 수 있습니다.
- 적 난이도는 `config.EnemyAIConfig`(반응 주기, 조준 오차, 회전 속도, 발사 간격, 기억 시간 등)로 조절합니다.
- 지형은 `GameConfig().terrain`(`TerrainConfig`)으로 설정합니다. 예: `cfg.terrain.map_pool = ("drift", "ring", "belt")`

## 재현성

맵과 전투는 `reset(seed)`로 만든 `numpy.random.Generator`를 사용합니다. 카드 추첨은 같은 seed로 초기화한 별도 생성기를 사용하므로 카드 창을 열어도 전투 난수열은 바뀌지 않습니다. 같은 seed에 같은 행동과 보상 선택을 넣으면 같은 결과가 나옵니다. `random_agent_test.py`와 `tests/test_progression.py`가 이를 확인합니다.

이미지 에셋은 없고, 맵 폴더만 `--add-data`로 함께 넣으면 됩니다(macOS/Linux에서는 `maps:maps`). 파일 경로는 모두 `config.resource_path()`로 만들기 때문에 실행 파일에서도 동작합니다.
