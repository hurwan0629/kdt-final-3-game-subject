# Space Skirmish

Python/Pygame 기반 탑뷰 우주선 슈팅 게임과 화면 없는 강화학습 환경입니다.

## 실행과 검증

```powershell
pip install -r requirements.txt
python main.py
python main.py --seed 42 --map belt
python main.py --random-map
python main.py --stage2
python main.py --no-terrain
python -m unittest discover -s tests -v
python random_agent_test.py
```

| 입력 | 동작 |

| 1–5 / 좌하단 + | 체력·공격력·사거리 및 탄속도·발사속도·이동속도 강화 |
| F2–F5 / 전직 카드 클릭 | 표시된 진화 선택 |

| ESC / P | 일시정지 설정 메뉴 |
| N | 다음 맵으로 새 게임 |

Q·Space 액티브 스킬은 제거했습니다. 설정 메뉴의 Q 종료 단축키는 유지합니다.

## 스탯과 성장

좌하단에는 다음 5종이 고정 순서로 항상 표시됩니다. 포인트가 없으면 강화할 수 없으며 발사속도 한계에 도달한 행은 MAX로 표시합니다.

| 번호 | 스탯 | 1포인트 효과 |
|---|---|---|
| 1 | 체력 | 최대 체력 +25, 현재 체력 +25(최대치 제한) |
| 2 | 공격력 | 주무기 피해 ×1.25 |
| 3 | 사거리 및 탄속도 | 탄속 ×1.2, 탄환 수명 ×1.15 |
| 4 | 발사속도 | 기본 발사 대기 ×0.85, 최소 4프레임 |
| 5 | 이동속도 | 이동 가속도 ×1.15 |

점수만큼 경험치를 얻고 다음 레벨의 요구량은 `60 + (현재 레벨 - 1) × 40`입니다. 일반 레벨업마다 강화 포인트 1개를 주며, 쓰지 않은 포인트는 계속 누적하고 화면에 표시합니다. 10의 배수 레벨은 별도의 전직·숙련 보상을 줍니다. 전직을 미뤄도 순서대로 선택할 수 있고 일반 강화와 남은 포인트는 유지됩니다. 새 게임·맵 변경 시 초기화합니다.

## 우주선 진화: 21종

모든 플레이어 우주선은 제공된 512×512 투명 PNG를 사용하며 원본은 오른쪽(0도)을 향합니다. 실제 파일명의 공백도 `ShipClass.asset`에 반영했습니다.

```text
베이직
├─ Lv10 트윈
│  ├─ Lv20 듀얼 스트라이커 → Lv30 개틀링 스톰
│  └─ Lv20 트리플 윙 → Lv30 펜타 윙
├─ Lv10 스나이퍼
│  ├─ Lv20 레일거너 → Lv30 하이퍼 레일건
│  └─ Lv20 헌터 → Lv30 프레데터
├─ Lv10 플랭크
│  ├─ Lv20 쿼드 윙 → Lv30 옥타 스타
│  └─ Lv20 트윈 플랭크 → Lv30 헥사 크루저
└─ Lv10 가디언
   ├─ Lv20 바스티온 → Lv30 콜로서스
   └─ Lv20 이지스 → Lv30 시타델
```

트윈 계열은 교차 연사·순차 4/6연사 또는 3/5방향 동시 탄막, 스나이퍼 계열은 모두 한 번에 일반 저격탄 1발을 발사하며 단계별 피해·탄속·사거리로 차별화합니다. 헌터·프레데터도 단발입니다. 플랭크 계열은 전후방·사방·8방향 또는 전후 쌍포와 측면포를 사용합니다. 가디언 계열은 큰 선체·높은 체력·피해 감소와 약한 소형 견제포를 갖습니다. 최종 진화는 직전 기체의 직계 자식 하나로 연결되고, Lv40부터 매 10레벨은 현재 기체 숙련 보상입니다.

탄환마다 탄약 1발을 사용합니다. 순차 발사는 실제 탄환이 나오는 시점에 탄약을 소모하고, 재장전·사망·전직 시 남은 연사 묶음은 취소합니다. 모든 탄환은 처음 맞은 대상에 피해를 주고 사라지며 벽에서 멈춥니다.

## 기체 크기와 전체 미니맵

플레이어와 적 우주선은 이전보다 가로·세로가 각각 2배이고 실제 충돌 반경도 2배입니다. 기본 선체 반경은 44px, 가장 큰 시타델은 96px입니다. 탄환은 기체별 포신 입구에 맞춰 물리 크기와 화면에서 보이는 폭을 함께 조정합니다.

오른쪽 아래에는 카메라·줌과 무관한 전체 미니맵이 표시됩니다. 밝은 회색 공간에 진한 회색 벽을 그리고 플레이어 위치와 방향만 표시합니다. 적 위치는 표시하지 않습니다.

## 맵

48px 타일의 60×45 전체 월드(2880×2160)에 맵마다 다른 하나의 연결된 블록 미로를 배치합니다. 기존 템플릿을 3×3 반복하지 않습니다. `drift`/`ring`/`belt`/`hello-world` 네 맵 모두 `terrain.generate_random_map`(큰 블록 격자를 DFS로 뚫는 diep.io 미로 모드)으로 맵마다 고정 시드를 줘서 한 번 생성한 뒤 `maps/*.txt`에 그대로 저장해 둔 것입니다. 통로/벽 블록이 8칸(384px)이라 가장 큰 시타델도 여유 있게 지나다닙니다. 은신 지형은 없고 경험치용 별 조각·행성은 유지합니다.

| 문자 | 지형 |
|---|---|
| `.` | 빈 공간 |
| `#` | 이동·탄환·시야를 막는 벽 |
| `~` | stage2에서 감속시키는 중력장 |
| `+` | stage2에서 파괴 가능한 벽, 기본은 일반 벽 |
| `P`, `E` | 플레이어·적 시작 위치 |

`drift`, `ring`, `belt`, `hello-world` 맵을 사용할 수 있습니다. 랜덤 맵도 큰 벽과 통로의 연결성을 검사합니다.

## 강화학습

기본 `TankEnv()`는 성장과 탄약 제한을 끄고, 이동 9방향 × 회전 3가지의 27개 행동으로 자동 발사합니다. 관찰은 기본 float32 길이 **241**(자기 8 + 적 24 + 천체 48 + 적 탄환 40 + 벽 121)입니다. 은신 채널이 사라져 기존 363차원 모델과 입력 크기가 다릅니다.

```python
from env import TankEnv
env = TankEnv()
observation, info = env.reset(seed=42)
observation, reward, terminated, truncated, info = env.step(0)
```

중력장·파괴 가능 벽을 모두 켜면 관찰은 483차원입니다. 같은 seed·행동·강화 선택은 같은 결과를 재현합니다. 성장 사용 시 `env.game.upgrade_stat(key)`와 `choose_reward(index)`로 별도 선택합니다.
