# 게임 이미지 에셋

**디자인 검토는 [전체 HTML 갤러리](index.html)를 브라우저에서 열어 확인하세요.** 실제 PNG 원본, 코드로 그린 UI의 실행 캡처, 이미지와 코드가 섞인 요소, 전체 화면과 미사용 이미지를 구분해서 볼 수 있습니다. 검색·종류 필터·확대 보기·밝은 배경 전환을 지원하며 서버나 인터넷 연결이 필요하지 않습니다.

플레이어 우주선 21종은 사용자가 제공한 512 × 512px 투명 배경 PNG입니다. 파일명과 원본 RGBA 데이터를 그대로 유지합니다. 플레이어와 적은 같은 PNG를 사용하며 정면은 오른쪽(0도)입니다. 방향성 탄환의 원본 이미지는 위쪽을 향합니다. 적의 선체는 붉은색, 엘리트는 금색으로 코드에서 변환합니다. Lv.10 가디언의 회색 포신은 코드에서 다시 그립니다.

화면용 로더는 청록색 실선체 경계를 측정해 선체 중심을 맞추고, 실선체 지름이 게임의 충돌 지름과 일치하도록 그립니다. 긴 포신과 투명 여백은 충돌 크기에 포함하지 않습니다. 전직 카드도 같은 이미지를 사용합니다. PNG 원본은 변경하지 않습니다.

## 그 외 에셋

게임에서 로드하는 PNG는 총 30개입니다. 배경 2개, 우주선 21개, 경험치 천체 3개, 중력장 1개, 탄환 3개입니다. 중력장은 `--stage2` 옵션을 켰을 때 사용합니다. 일반 벽과 파괴 가능한 벽은 코드로 그립니다.

- `made_by_code/`: 실제 Renderer로 촬영한 UI·효과·전체 화면 48개. 게임용 PNG로 교체한 것이 아닌 문서용 캡처입니다. 일부 상태는 검토를 위해 직접 설정했으며 자연 플레이 기록이 아닙니다.
- `trash/`: 미사용 원본 PNG 22개를 원래 하위 폴더 구조대로 보관했습니다. 영문 우주선 13개, 예전 적 3개, 예전 지형 3개, 미사일·지뢰 2개, 진화 트리 참고 이미지 1개입니다.
- 미사일·지뢰는 렌더러 분기가 남아 있지만 현재 발사 로직에서는 생성하지 않습니다. 기능을 복원할 때 해당 PNG를 원래 경로로 돌려놓아야 합니다.

파일별 해상도·바이트 크기·SHA-256·상태(`active`, `capture`, `archived`)·렌더링 코드 위치는 [catalog.json](catalog.json)에 있습니다. 기존 원본의 투명도·선체 경계 메타데이터는 보존했습니다. 이동한 파일에는 `original_path`도 기록했습니다. 기존 생성 이미지의 제작 기록은 [generation-prompts.json](references/generation-prompts.json)에 있으며, 이 파일 안의 경로는 생성 당시의 기록입니다. 루트의 `assets.zip`도 기존 보관본으로 변경하지 않았습니다.

갤러리와 캡처는 프로젝트 루트에서 `python docs/dev/build_asset_gallery.py`로 재생성합니다. 게임 의존성인 pygame·numpy만 필요합니다. 원본 52개의 보존, PNG 목록, 카탈로그, HTML 내부 파일 링크를 함께 검증합니다.
