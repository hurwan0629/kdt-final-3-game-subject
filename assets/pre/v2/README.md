# v2 이미지 보관본

2026-10-18 새 아트 적용 전의 이미지와 기존 미사용 PNG 29장을 보관합니다. 게임은 이 폴더의 이미지를 불러오지 않습니다. 파일은 픽셀 변경 없이 이동했으며 원래 폴더 구분을 유지합니다.

- `backgrounds/`: 교체 전 배경 2장
- `objects/`: 교체 전 천체·중력장 4장과 기존 미사용 벽·구름 3장
- `enemies/`: 기존 미사용 적 우주선 3장
- `projectiles/`: 기존 미사용 지뢰·유도탄 2장
- `ships/`: 기존 미사용 우주선 13장과 참고용 진화 트리 1장
- `references/`: 문서용 진화 트리 1장

[manifest.json](manifest.json)은 이동 전후 경로와 SHA-256을 기록합니다. [catalog.json](catalog.json)은 교체 전 메타데이터 목록이며, 목록의 `path`는 당시 `assets/` 기준 경로입니다. 계속 사용하는 우주선·탄환은 현재 `assets/`에 남아 있습니다.
